# 静态词目补齐与独立词组权重

本次为0.2.0后的未发布本地数据更新。用户指定维护此独立仓库，不提交、不推送、不发布。

固定来源提交927e1cf1d3eeb9bf4be85e3f684dba4dd485b6f6。静态词目集合包含六张中文字/词表、根拼音表、拆字字表、英文表、中英混输表、自定义短语、OpenCC静态映射的键与完整候选值、symbols的完整候选值。排除结构键、注释、维护错词样例、OpenCC控制分隔行和无限动态输出。只保证固定快照和明确声明的静态集合，不声称实现Rime全部触发/脚本功能。

保留原有词目、词对及权重。words/catalog/expanded仅增量补新增词；自动音继续固定pypinyin0.55.0，原A/E/L/U为基础词目注音来源状态，新显式来源词表独立提供额外读音，不以它改写历史自动音状态。词目存在、可拼音查询、具体输入法候选排名分开验证。

新增default词表data/pinyin/rime_ice/lexicon.tsv，提供五张默认中文表中的显式拼音与正整数词组权重；同词对按8105/base/ext/tencent/others来源顺序首条优先。腾讯文字无显式读音，不假造；自动音由原vocabulary流程承担。既有单字词对不加权，新单字读音为1，避免文字总频率覆盖既有读音分档。所有旧默认词对保留；新表与旧表可重合，由消费者按同词对max合并。

直接复制上游几十万权重的测量造成nh/你好等退化，最终词组映射为项目尺度max(1, min(8192, raw_weight // 64))，保留原快照供追溯。该上限低于Flower既有16384日常prior，不改变既有词对/overlay/用户顺序的权重，也不伪称运行表是原始统计频次。各消费者仍负责其自身排名；记录未校准试验，不把退化试验作为通过证据。

新增来源仅许可标记为GPL-3.0-only，保留完整许可及来源文件身份，不用它覆盖既有数据许可或NOASSERTION。源快照入源码仓库，crate只带运行表、明确覆盖、通知和许可；离线check及刷新不联网，不执行上游代码。新增同步生成器使用固定维护工具PyYAML6.0.3与pypinyin0.55.0，Rust消费者零新增依赖；原build_vocabulary.py --check仍仅用标准库。同步器须先验证旧词库、源字节和工具版本，支持只读check，重复运行无新增时不改写。

默认总词对数量由新增来源coverage报告计算；原vocabulary coverage仍报告既有基线+自动扩充子系统，明确不重复计新来源重叠项。Rust API与DEFAULT_TSV、TABLES及asset映射保持一致，目录资产白名单同步。发布后消费者才能锁定新的真实Git提交，本地更新不代表远端已接入。
